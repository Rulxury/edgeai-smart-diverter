# 🧠 IMPLEMENTATION PLAN: EDGE-AI (TINYML) & HARDWARE SYNCHRONIZATION
**Dokumen Spesifikasi Prototipe 2: Smart Load-Diverter Neural Network**

Dokumen ini merupakan panduan arsitektur dan implementasi bagi tim Data/AI Engineer. AI yang dirancang di sini berwujud *Software* yang akan ditanamkan ke dalam memori SoC (ARM Cortex) untuk bertindak sebagai "Otak" pengambil keputusan. 

**Sinkronisasi dengan RTL (IP Core):** 
Model AI ini akan menghitung probabilitas urgensi pengalihan daya secara *real-time*. Berdasarkan perhitungan tersebut, CPU utama akan mengonversinya menjadi angka batas arus (Threshold) dan menuliskannya langsung ke `THRESHOLD_REG` pada *offset* `0x08` di modul `smart_diverter_apb.v` melalui bus APB. Jika arus nyata melebihi batas yang ditetapkan AI ini, perangkat keras akan otomatis memicu `relay_out`.

## 🔬 RINCIAN KOMPONEN PROTOTIPE EDGE-AI

### 1. Dataset Sintetis (`dummy_energy_data.csv`)
**Fungsi:** "Buku pelajaran" bagi AI untuk mengenali pola kapan energi surya harus disimpan ke toren/pemanas agar tidak bocor ke jaringan PLN (mencegah *Grid-Defection curtailment*).
**Spesifikasi Desain:**
Karena kita tidak memiliki waktu untuk mengumpulkan data sensor riil selama berbulan-bulan, kita menggunakan skrip Python (Pandas/Numpy) untuk men-generate ribuan baris data skenario logis.
*   **Fitur Input (X):**
    *   `jam` (6.00 - 18.00): Mengindikasikan ketersediaan matahari.
    *   `cuaca` (0=Hujan, 1=Mendung, 2=Cerah): Mempengaruhi lonjakan produksi energi.
    *   `daya_surya` (Watt): Produksi listrik aktual pada saat itu.
    *   `toren_persen` (0-100%): Status ketersediaan ruang penyimpanan air sekunder.
    *   `suhu_heater` (°C): Status panas dari *water heater*.
*   **Label Output (Y):** 
    *   `1` (Alihkan Daya) atau `0` (Normal). Logika pembentukannya adalah: *Jika daya surya melimpah DAN penyimpanan (toren/heater) belum penuh, maka Alihkan (1).*

### 2. Skrip Pelatihan Neural Network (Arsitektur Lightweight MLP)
**Fungsi:** Membangun kecerdasan buatan berbasis *Deep Learning* yang sangat efisien, bukan sekadar logika *if-else* biasa.
**Spesifikasi Desain:**
Kita menggunakan TensorFlow/Keras untuk membangun *Multi-Layer Perceptron* (MLP) yang dangkal namun akurat.
*   **Input Layer:** 5 Neuron (Sesuai dengan 5 fitur input di atas yang sudah dinormalisasi antara nilai 0 hingga 1).
*   **Hidden Layers:** 2 Lapisan berukuran kecil (misalnya 8 neuron dan 4 neuron) dengan fungsi aktivasi `ReLU` agar komputasinya sangat cepat di dalam prosesor SoC.
*   **Output Layer:** 1 Neuron dengan aktivasi `Sigmoid`. Keluaran dari model ini bukanlah angka mutlak 1 atau 0, melainkan **probabilitas (0.0 hingga 1.0)**. 
*   **Sinkronisasi ke Hardware:** Jika model mengeluarkan probabilitas 0.9 (90% yakin daya harus dialihkan), CPU mikrokontroler akan menurunkan batas `THRESHOLD_REG` ke angka yang rendah (misal 1000W) agar IP Core Verilog (`smart_diverter_apb.v`) segera memicu `relay_out` menjadi `1`.

### 3. Log & Grafik Evaluasi Model (Bukti Matematis untuk Proposal)
**Fungsi:** Bukti (*Proof-of-Concept*) visual bagi juri bahwa model AI benar-benar dilatih dengan benar, tidak mengalami *overfitting*, dan akurat.
**Spesifikasi Desain:**
*   **Training History:** Skrip Python akan diinstruksikan untuk mem-plot grafik *Loss* dan *Accuracy* dari tiap *epoch* (siklus pelatihan).
*   **Target Output:** Tangkapan layar (*screenshot*) grafik garis yang menunjukkan akurasi model mencapai >90%.
*   **Narasi untuk Juri:** "Kami menggunakan arsitektur Neural Network yang dievaluasi secara ketat. Grafik akurasi ini membuktikan bahwa algoritma AI kami stabil dan dapat mengambil keputusan presisi tinggi pada berbagai skenario fluktuasi cuaca ekstrem."

### 4. Model Kuantisasi TFLite (`smart_diverter.tflite`)
**Fungsi:** Mengompresi model AI yang tadinya berat dan boros memori menjadi versi *TinyML* super ringan yang bisa masuk ke memori mikrokontroler (*Edge Device*).
**Spesifikasi Desain:**
*   Model asli dari Keras biasanya menggunakan angka desimal presisi tinggi (*32-bit float*). Jika dimasukkan ke mikrokontroler, ini akan membuat sistem melambat dan memakan RAM.
*   **Proses:** Menggunakan pustaka `tf.lite.TFLiteConverter`, kita menerapkan optimasi (*Quantization*). Proses ini merampingkan bobot arsitektur AI menjadi *8-bit integer* tanpa mengurangi kecerdasannya secara signifikan.
*   **Hasil:** Sebuah file biner `.tflite` berukuran sangat kecil (biasanya hanya beberapa Kilobyte) yang dirancang khusus untuk arsitektur ARM Cortex-M yang menjadi inang dari IP Core Verilog kalian.

### 5. C-Byte Array Header (`model.h`)
**Fungsi:** Jembatan pamungkas antara dunia rekayasa perangkat lunak (Software) dan dunia rekayasa perangkat keras (Hardware).
**Spesifikasi Desain:**
*   SoC tingkat rendah tidak bisa membaca file `.tflite` seperti halnya komputer biasa. Biner TFLite tersebut harus diterjemahkan menjadi kode bahasa C murni.
*   **Eksekusi:** Skrip Python akan mengekstrak file `.tflite` tadi menjadi struktur *array hexadecimal* panjang dalam bahasa C, contohnya: `const unsigned char diverter_tflite_model[] = { 0x1c, 0x20, 0x05, 0x00 ... };`.
*   **Alur Kerja Final di dalam SoC:**
    1. Kode C ini (`model.h`) di-*compile* bersama *firmware* utama mikrokontroler.
    2. Pustaka *TensorFlow Lite for Microcontrollers* di CPU ARM akan membaca *array* ini sebagai sebuah "Otak".
    3. CPU membaca sensor, meminta Otak memberikan keputusan.
    4. CPU mengeksekusi keputusan tersebut dengan melakukan *write access* (`PWRITE = 1`) ke alamat `0x08` (`PADDR = 4'h8`), lalu mengisi datanya (`PWDATA = [nilai_threshold_baru]`).
    5. Menghasilkan respons instan (*zero-latency*) oleh modul Verilog yang langsung memicu `relay_out` saat arus surya melewati batas tersebut.
